# IntelliDesk 常见问题（FAQ）

> 最后更新：2025-07-20

---

## 账号与注册

### Q: 注册需要什么信息？

只需要一个有效邮箱即可注册。注册后默认创建免费版工作区，不需要绑定信用卡。

### Q: 可以用 Google / GitHub 账号登录吗？

Enterprise 版支持通过 SSO 对接 Google / GitHub OAuth。免费版和 Pro 版目前只支持邮箱注册。

### Q: 如何删除我的账号？

在控制台 → 「设置」→ 「账号安全」→ 页面底部点击「删除账号」。注意：删除账号后所有知识库、对话记录将被永久清除，不可恢复。

## 知识库

### Q: 支持哪些文档格式？

支持 Markdown（`.md`）、PDF（`.pdf`）、Word（`.docx`）、纯文本（`.txt`）四种格式。

### Q: Pro 版的 OCR 是什么意思？

OCR（光学字符识别）用于识别扫描版 PDF 和图片中的文字。如果你的文档是扫描件（图片形式的 PDF，文字无法选中），免费版无法读取，需要 Pro 版及以上。

### Q: 知识库的检索准确率低怎么办？

1. 检查文档是否按 Markdown 标题层级组织（标题越清晰，切分越准确）
2. 在知识库设置中降低相似度阈值（0.70 → 0.50）
3. 增大 Top-K 值（3 → 5）
4. 如果使用 Pro 版，开启 Rerank 重排序
5. 检查问题中是否包含错别字（会影响 Embedding 质量）

### Q: 免费版能建几个知识库？

免费版只能创建 **1 个知识库**。如果需要在同一工作区分管多个产品的文档，请升级到 Pro 版（10 个知识库）或 Enterprise 版（不限）。

## API 集成

### Q: 免费版能用 API 吗？

**不能**。API 访问是 Pro 版及以上才有的功能。免费版只能通过控制台网页和网页嵌入组件使用。

### Q: API 的速率限制是多少？

- **免费版**：不支持 API
- **Pro 版**：300 次/分钟
- **Enterprise 版**：无限制

### Q: API Key 在哪里获取？

控制台 → 「设置」→ 「API Keys」→ 点击「创建 API Key」。请注意：API Key 只在创建时展示一次，之后无法查看，需要妥善保管。如果遗失，需要创建新的 Key。

### Q: 怎样通过 API 创建会话并发送消息？

```bash
# 1. 创建会话
curl -X POST https://api.intellidesk.com/v2/sessions \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"workspace_id": "ws_xxxxxxxx"}'

# 2. 发送消息（使用返回的 session_id）
curl -X POST https://api.intellidesk.com/v2/chat \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"session_id": "sess_abc123", "message": "如何上传文档？"}'
```

## 对话与 Agent

### Q: Agent 有时候回答不准确怎么办？

1. 确认知识库中确实包含正确答案（在控制台用「测试」面板验证）
2. 在 System Prompt 中加入"如不确定，请诚实告知"的约束
3. Pro 版用户建议开启 Rerank
4. 降低 Agent Temperature（控制台 → Agent → 高级设置 → Temperature 设为 0.3）

### Q: 能设置 Agent 在不知道答案时拒绝回答吗？

可以。在 System Prompt 中明确加入：

> 如果知识库中没有找到相关信息，请回复"抱歉，我暂时无法回答这个问题，建议您联系人工客服。"不要猜测或编造答案。

### Q: 对话记录可以导出吗？

可以。在控制台 → 「对话记录」→ 选择日期范围 → 点击「导出」。支持 Markdown 和 CSV 两种格式。Pro 版还支持导出为 PDF。

### Q: Agent 支持多语言吗？

知识库检索支持中、英、日、韩等 50+ 语言（取决于 Embedding 模型）。Agent 回复语言取决于 System Prompt 设置和用户输入的语言。

## 费用与计费

### Q: 免费版真的完全免费吗？有没有隐藏费用？

免费版**完全免费**，不需要绑定信用卡。限制只有：1 个知识库、100 次对话/月、不支持 API。没有隐藏费用，不会自动扣款。

### Q: 超额后会立刻停止服务吗？

- **免费版**：100 次用完后无法继续对话，下月 1 日重置
- **Pro 版**：超出 5,000 次按 ¥0.05/次 计费，有 3 天宽限期
- **Enterprise 版**：无限制

### Q: 年付和月付可以切换吗？

可以。月付切换年付立即生效，已有月付费用按剩余天数折算抵扣。年付期间不能切换回月付，到期后可更改。

### Q: 知识库数据会因为我降级而丢失吗？

- 从 Pro 降级到免费版：超出部分（1 个知识库 / 10 MB 以外的数据）保留 30 天，30 天后永久删除
- 从 Enterprise 降级到 Pro：自定义工具配置和审计日志历史保留 30 天
- 数据不因欠费立即删除，有充足时间备份

## 安全与隐私

### Q: 我的文档数据会被用来训练模型吗？

**不会**。你的文档数据和对话记录仅用于提供智能客服服务。IntelliDesk 不会用客户数据训练模型，这是写入服务协议的承诺。

### Q: 数据存储在哪里？

数据默认存储在 **AWS 新加坡区域**。Enterprise 用户可选择存储区域（新加坡、法兰克福、东京）。中国区用户可通过阿里云上海区域接入（Enterprise 专属）。

### Q: IntelliDesk 有安全认证吗？

已通过 **SOC 2 Type II** 审计。Enterprise 版支持 SSO（SAML 2.0 / OIDC）、审计日志、IP 白名单等安全功能。
