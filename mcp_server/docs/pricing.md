## 免费版限制详解

免费版适合个人开发者和小型项目试用。以下是重要限制：

### 知识库限制
- **1 个知识库**：只能创建一个知识库，如果需要多产品/多语种文档需分别建库，免费版不支持
- **10 MB 文档总大小**：大约相当于 200 页纯文本 Markdown 文档
- **单文件 5 MB**：超大 PDF 无法上传，需要先压缩或拆分

### 调用限制
- **100 次对话/月**：用户每发送一条消息计为 1 次对话。100 次用完后 Agent 会回复"本月额度已用完，请升级套餐"
- **30 次/分钟**：同一 API Key 每分钟最多 30 次请求，超出返回 HTTP 429

### 功能限制
- **无 API 访问**：免费版只能通过网页控制台使用，不能通过 REST API 集成到自己的应用中
- **无 Rerank**：检索精度取决于 Embedding 相似度，搜索较长文档时可能出现不相关内容

## Pro 版与免费版的差异

### 适合场景
- 中小团队的产品客服
- 需要 API 集成到自有平台的开发者
- 文档量中等（< 500 MB）

### 主要突破
- **API 开放**：可以调用 REST API 将 IntelliDesk 嵌入任意平台
- **Rerank 重排序**：启用后检索精度提升约 30%（基于 Cohere Rerank v3）
- **OCR 支持**：扫描版 PDF 和图片中的文字可被识别和索引
- **速率提升**：300 次/分钟足够支撑日均 5000+ 次对话

### 计费说明

- **超额计费**：超出 5,000 次的部分按 ¥0.05/次 计费
- **暂停机制**：余额不足时服务不会立即停止，有 3 天宽限期
- **降级规则**：取消续费后，次月自动降为免费版，超出部分的数据只保留 30 天

## Enterprise 版专属功能

### 自定义工具

Enterprise 版支持用户注册自定义 API 作为 Agent 的 Tool。步骤：

1. 在控制台 → 「工具」→ 「自定义工具」点击「新建」
2. 填写工具名称、描述（Agent 用这个描述判断何时调用）
3. 填写 API Endpoint、请求参数 Schema、认证方式
4. 点击「测试」验证连接
5. 发布后 Agent 即可调用

```json
{
  "name": "query_inventory",
  "description": "查询商品库存数量。当用户询问某商品是否有货时调用。",
  "method": "POST",
  "endpoint": "https://your-api.com/inventory",
  "headers": { "Authorization": "Bearer your-api-key" },
  "parameters": {
    "sku": { "type": "string", "required": true, "description": "商品SKU编号" }
  }
}
```

### SSO 单点登录

支持 SAML 2.0 / OIDC 协议，可与企业已有的账号体系（Okta、Azure AD、飞书等）打通。

### 私有化部署

Enterprise 年付用户可选择私有化部署方案（另议）。IntelliDesk 不提供本地部署包，部署在由 IntelliDesk 管理的独立 VPC 中，数据物理隔离。

## 常见计费问题

### Q: 对话次数如何计算？

每次用户发送消息并收到 Agent 回复计为 1 次对话。Agent 内部反复检索知识库、调用工具的过程不计入对话数。

### Q: 可以从 Free 直接升到 Enterprise 吗？

可以。从任一方案升级都立即生效，已付费用按剩余天数折算抵扣。

### Q: 如果 100 次用完了，我的知识库数据还在吗？

数据**永久保留**。额度用完后只是无法继续对话，下个月 1 日额度自动重置。你也可以随时升级以立即恢复服务。
