# McpToolServer 阿里云 ECS 部署指南

## 一、服务器准备

```bash
# 1. SSH 登录
ssh root@你的服务器IP

# 2. 安装 Docker（推荐）
yum install -y docker
systemctl start docker
systemctl enable docker

# 3. 安装 docker-compose
curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
chmod +x /usr/local/bin/docker-compose
```

## 二、安全组配置

阿里云控制台 → ECS → 安全组 → 入方向 → 添加规则：

| 端口 | 来源 | 说明 |
|---|---|---|
| 8100 | 0.0.0.0/0 | McpToolServer API |

> ⚠️ 如果只想让 IntelliDesk 调用，来源填 IntelliDesk 所在服务器的 IP，不要开放给全网。

## 三、上传项目

```bash
# 本地打包上传
cd D:/McpToolServer
tar -czf mcptoolserver.tar.gz --exclude=venv --exclude=__pycache__ .

# SCP 上传
scp mcptoolserver.tar.gz root@你的服务器IP:/opt/

# 服务器上解压
ssh root@你的服务器IP
cd /opt
tar -xzf mcptoolserver.tar.gz
mv /opt/McpToolServer/* /opt/mcptoolserver/
```

## 四、配置环境变量

```bash
cd /opt/mcptoolserver
cp .env.example .env
vim .env
```

填入：
```
EMBEDDING_API_KEY=sk-你的硅基流动key
EMBEDDING_BASE_URL=https://api.siliconflow.cn/v1
EMBEDDING_MODEL_NAME=BAAI/bge-m3
```

## 五、启动（二选一）

### 方案 A：Docker（推荐）

```bash
cd /opt/mcptoolserver
docker compose up -d

# 查看日志
docker compose logs -f

# 验证
curl http://localhost:8100/health
```

### 方案 B：Systemd（不用 Docker）

```bash
# Python 环境
yum install -y python3 python3-pip
pip3 install -r /opt/mcptoolserver/requirements.txt

# 安装 systemd 服务
cp /opt/mcptoolserver/deploy/systemd.service /etc/systemd/system/mcptoolserver.service
systemctl daemon-reload
systemctl start mcptoolserver
systemctl enable mcptoolserver

# 查看状态
systemctl status mcptoolserver
journalctl -u mcptoolserver -f
```

## 六、验证

```bash
# 本地验证
curl http://localhost:8100/health

# 外网验证（用你服务器的公网 IP）
curl http://你的公网IP:8100/mcp/tools
```

## 七、IntelliDesk 配置

修改 IntelliDesk 的 `.env`：

```ini
USE_MCP=true
MCP_SERVER_URL=http://你的公网IP:8100
```

重启 IntelliDesk 即可。
