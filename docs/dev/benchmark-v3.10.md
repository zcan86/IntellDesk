# IntelliDesk v3.10 性能基准

> 测试时间: 2026-07-31 | 测试集: 22条模拟用户查询

---

## 路由命中率: 95%

| 路由层 | 命中数 | 示例 |
|---|---|---|
| 精确匹配 (cache) | 5 | 你好、在吗、谢谢、再见 |
| 关键词 (keyword) | 8 | 退货流程、包邮、支付方式、门店 |
| 正则+数据库 (db) | 2 | DD20240730001、物流查询 |
| 语义 (semantic) | 6 | 我想退东西、快递到哪了、多少钱包邮 |
| Agent 透传 | 1 | Air Force 1 和 Dunk 哪个更适合跑步 |
| **合计** | **21/22 (95%)** | |

## 响应时间

| 路径 | 耗时 | 对比 |
|---|---|---|
| 缓存命中 | 0.1ms | — |
| 数据库查询 | 1.2ms | 12x 缓存 |
| Agent (LLM+工具) | 2000-5000ms | 20,000-50,000x 缓存 |

## Token 节省

以 100 次对话估算：

| | 全部走Agent | 95%路由命中 | 节省 |
|---|---|---|---|
| LLM 调用次数 | 100 | 5 | 95 次 |
| Token 消耗 | ~80,000 | ~10,000 | 70,000 |
| 成本 (DeepSeek) | ~¥0.16 | ~¥0.02 | ¥0.14 |

## Memory 优化

| | 升级前 | 升级后 |
|---|---|---|
| 消息上限 | 无限制 | 5 轮 (10条) |
| 第 20 轮对话 | 40 条消息, 可能超 context | 始终 10 条 |
| 闲置会话 | 永久保留 | 60 分钟 TTL 自动清空 |

## 架构升级总结

| 维度 | 升级前 | 升级后 |
|---|---|---|
| 网关 | 无 | API Key鉴权 + 30次/分限流 |
| 路由 | 全走 Agent | 4 层路由 (95%零LLM) |
| 订单 | Mock 硬编码 | SQLite 3用户/7订单 |
| 退款 | 静态文本 | 三重条件校验 |
| 记忆 | 无限累积 | 5轮窗口 + 60分TTL |
| 反馈 | 无 | 打星 + 评论 + 统计 |
| 画像 | 无 | 消费/偏好/等级 |
