# IntelliDesk — 基于 Adaptive-RAG 的多智能体电商客服

针对 FAQ 客服长尾命中率低、常规 RAG 幻觉严重的痛点，设计并实现了基于 Adaptive-RAG 的多智能体电商客服系统。

**多智能体架构**：基于 LangGraph 搭建 Agent 状态机，采用 Prompt-template + DeepSeek 构建 7 类意图路由节点，LLM 自主决策分类（准确率 97%），统一接入 10 个核心工具（知识库/订单/物流/退换货/商品/图片识别/语音/天气/计算/时间），实现 SSE 流式输出与多轮对话记忆。

**检索阶段**：4 份业务文档经双层切分后构建 ChromaDB + BGE-m3 向量索引。基于 Adaptive-RAG 实现策略路由——查询分析→混合检索→RRF 融合→LLM Rerank→Self-RAG 反思，动态适配不同复杂度问题。混合检索（BM25+BGE-m3）弥补纯语义对精确关键词不敏感的缺陷，同义改写查询从字面零匹配提升为语义命中。

**Skill + MCP 可插拔体系**：将工具封装为独立 MCP Server（独立 Git 仓库 + Docker 部署），本地 @tool 与远程 MCP 统一为 Function Calling 接口，配置一键切换。MCP 不可用时自动降级本地模式。

**多模态识别**：集成 Qwen-VL-Max 实现图片识别→库存校验→报价推荐闭环，店内无货时诚实告知并推荐类似款。VLM 不可用时友好降级。

**兜底机制**：MCP/VLM 双层自动降级，System Prompt 硬约束诚实原则，21 个测试用例覆盖核心链路。
