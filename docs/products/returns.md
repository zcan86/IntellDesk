# 速购电商 — 退换货政策

> 最后更新：2025-07-01

---

## 一、退货政策

### 7 天无理由退货

| 条件 | 说明 |
|---|---|
| 适用商品 | 除生鲜、定制商品、内衣等特殊品类外的大部分商品 |
| 时间限制 | 签收后 **7 天内** 申请 |
| 商品状态 | 未使用、包装完好、配件齐全 |
| 运费 | 非质量问题买家承担；质量问题商家承担 |

### 退货流程

1. App → 我的订单 → 选择订单 → 申请退货
2. 填写退货原因（质量问题/不想要/发错货）
3. 质量问题需上传商品照片
4. 1-2 个工作日审核
5. 审核通过后获取退货地址，寄回商品
6. 仓库签收后 1-3 个工作日原路退款

### 不适用无理由退货

- 生鲜食品、易腐商品
- 定制类商品（刻字、定制尺寸）
- 内衣、泳衣等贴身衣物
- 已激活的数码产品（手机、平板）
- 已下载的虚拟商品（充值卡、游戏点卡）

---

## 二、换货政策

签收后 **15 天内**，质量问题可申请换货，运费商家承担。

---

## 三、特殊情况

| 场景 | 处理方式 |
|---|---|
| 发错货 | 商家承担退回运费并重新发货 |
| 少发货 | 核实后补发或退款 |
| 商品破损 | 签收时拒收；已签收 24 小时内联系客服 |
| 尺码不合适 | 适用 7 天无理由退货，买家承担运费 |

---

## 四、退款时效

| 支付方式 | 到账时间 |
|---|---|
| 微信/支付宝 | 1-3 个工作日 |
| 银行卡 | 3-7 个工作日 |
| 平台余额 | 即时到账 |
