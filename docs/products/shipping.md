# 速购电商 — 配送说明

> 最后更新：2025-07-01

---

## 一、配送方式

| 快递 | 时效 | 费用 |
|---|---|---|
| 顺丰速运 | 1-2 天 | ¥12 起 |
| 中通快递 | 2-4 天 | ¥6 起 |
| 圆通快递 | 2-4 天 | ¥6 起 |
| EMS | 3-5 天 | ¥15 起 |

## 二、包邮政策

- 订单金额满 **¥99** 全国包邮（偏远地区除外）
- 偏远地区：新疆、西藏、青海、宁夏 → 满 ¥199 包邮
- 自提点取货：全部免运费

## 三、配送时效

- 当日 16:00 前下单，当天发货
- 16:00 后下单，次日发货
- 预售商品按页面标注时间发货
- 节假日顺延

## 四、物流查询

- App → 我的订单 → 点击订单 → 查看物流
- 或联系客服提供订单号查询

## 五、常见配送问题

### 长时间未收到
超过预计时效 3 天未收到，联系客服核查，确认丢件后补发或退款。

### 包裹破损
签收时发现外包装破损可拒收；已签收的拍照联系客服处理。
