# IntelliDesk — 基于 Adaptive-RAG 的多模态电商客服系统

针对 FAQ 长尾命中率低、常规 RAG 幻觉严重的痛点，实现基于 Adaptive-RAG 的多模态电商客服系统。

**Agent 架构**：LangGraph 搭建 ReAct Agent 状态机，经网关（鉴权/限流/并发排队）进入 4 层请求路由（精确/关键词/订单正则/语义），短路 95% 请求零 LLM 成本；内置 LLM 意图识别（7 类），统一接入 9 个工具（知识库/订单/物流/退换货/商品/图片/语音/计算/时间），支持 SSE 流式输出与多轮记忆（5 轮 + 60min TTL）。

**检索阶段**：4 份业务文档双层切分构建 ChromaDB + BGE-m3 索引。Adaptive-RAG 策略路由：查询分析→混合检索→RRF→LLM Rerank→Self-RAG 反思，复杂问题自动拆子查询；BM25+BGE-m3 混合检索弥补纯语义对精确关键词不敏感，同义改写由零匹配提升为语义命中。

**MCP 可插拔工具层**：工具封装为独立 MCP Server 进程（HTTP 协议发现/调用），Agent 不直接 import 工具代码，功能解耦 + Docker 独立部署；调用失败返回友好提示，不影响会话。

**多模态识别**：Qwen-VL-Max 图片识别→Agent 结合商品库报价推荐；VLM 不可用降级硅基流动兜底，店内无货诚实告知并推荐类似款；语音走 Whisper 转写，不可用降级文字交互。

**兜底与质量保障**：MCP/VLM 双层降级，System Prompt 硬约束诚实原则，并发排队 + 超时降级 503；21 个测试用例覆盖核心链路。
